# DB 마이그레이션

MySQL 테이블을 만들거나 바꾸는 SQL 파일이다. 번호 순서대로 **수동으로** 실행한다(자동으로 실행하지 않는다).

- 이미 만든 파일은 고치지 않는다. 바꿀 내용은 다음 번호의 새 파일로 추가한다.
- 공용 DB에는 DB 담당자가 적용한다. 적용하기 전에 파일을 검토한다.
- 파일 이름은 `번호4자리_내용.sql`이다.

| 파일 | 내용 |
|---|---|
| `0001_create_documents_info.sql` | 문서 목록 테이블(`documents_info`). 현재 DB에 있는 정의 그대로다. 이미 있으면 아무것도 하지 않는다 |
| `0002_add_chunk_count_error_message.sql` | `chunk_count`(완료 시 청크 수), `error_message`(실패 사유) 컬럼 추가. 한 번만 실행한다(다시 실행하면 이미 있는 컬럼 오류가 난다) |
