# MANSA 평가 질문·정답 기준 — 50문항 (v2.1)

현장 물류설비 기술과 안전 기준을 하나로 찾고 답하는 AI 지식 탐색 서비스의 평가 자료다. 이번 세트는 `엘트론엘리베이터_기술사양서.pdf`와 `안전기준.pdf`만 사용한다. 기술 문서의 ELVRO 3000·HYDRO 501 모델과 세부 형번을 대상으로 한다.

## 판정 방법

- 모델 제원 S01–S20: 지정한 제품군·형번의 제원이나 기술 특성을 정확하게 답해야 통과한다.
- 안전 관리 A01–A20: 질문에 명시한 모델·조건에 맞는 안전 기준을 답해야 통과한다.
- 복합 참조 X01–X10: 해당 모델의 기술 정보와 안전기준을 함께 적용해야 통과한다.
- **모든 문항에서 되묻기는 실패다.** 모델·부위·조건을 다시 물으면 일부 정답 내용이 함께 있어도 실패다. 답변 불가도 실패다. 필요한 조건은 질문 또는 근거 문서에 있다.
- 정답 수치가 포함되어도 되묻기나 잘못된 안전 내용이 있으면 전체 문항은 실패다.
- 표현이 달라도 의미·수치·단위·적용 조건이 맞으면 인정한다. 질문의 계산 가정은 제품의 실제 제원으로 단정하지 않는다.
- PDF 페이지는 첫 페이지를 1로 센 번호이며 인쇄된 쪽수와 다를 수 있다.
- 제공된 안전기준 PDF의 KC 2050-51 : 2022 표기를 기준으로 한 평가이며 현행 규정 여부를 검증한 자료는 아니다.

## 현재 평가 페이지와의 관계

`testsets/tech_qa.json`의 필수 필드는 기존 `load_testset()`과 호환된다. 제원은 `L3`, 안전·복합은 `L2`라는 기존 형식의 분류를 사용한다. 실제 QA 처리 경로와 같다는 뜻은 아니다.

`category`, `reference_answer`, `accepted_outcomes`, `rejected_outcomes`, `clarification_policy`, `acceptance_criteria`, `reference_sources`, `review_notes`는 검토용 추가 필드다. **현재 평가 코드는 이 필드를 읽지 않으므로 이 파일만 바꿔서는 되묻기를 자동 실패 처리하지 않는다.** 되묻기 발생 문항은 최종 검토에서 반드시 실패로 기록한다. 자동 실패 처리를 적용하려면 평가 코드의 변경이 별도로 필요하다.

수치가 정답의 필수 요소인 안전 문항에도 `expected_numbers`를 채웠다. 빈 목록은 수치 포함 검사만으로 채점할 문항이 아니라는 뜻이며, 되묻기 허용을 뜻하지 않는다. 현재 수치 채점은 단위 환산을 인정하지 않으므로 의미가 같은 환산 응답은 수동 검토한다. 표현 일관성 점수만으로 정답 여부를 판단하지 않는다.

현재 `LlmAnswerer`는 질문만 LLM에 전송하고 문서 검색을 수행하지 않는다. 이 테스트셋을 지정하는 것만으로 RAG 평가가 되지는 않는다. PDF 파일명·페이지·절 번호는 `reference_sources`에 기록했다. `expected_sources`에는 `엘트론엘리베이터_기술사양서.pdf#p6`, `안전기준.pdf#p9` 같은 페이지 키를 넣었다. 파일명은 사용자가 확인한 Chroma source 값과 정확히 같으며, 페이지는 PDF 첫 페이지를 1로 센 번호다. 응답기의 `retrieved_ids`와 `cited_ids`도 같은 페이지 키를 반환해야 기존 문자열 비교로 채점할 수 있다. 청크 ID를 반환한다면 응답기에서 source와 페이지 메타데이터로 변환해야 한다. 복합 문항의 검색 적중률은 현재 코드상 정답 페이지 중 하나만 검색돼도 통과하고, 출처 정확도는 정답 페이지가 모두 인용돼야 통과한다.
